# 《天宫弈 · 南天门守卫战》 (Tiangong Celestial Court TD)

一款面向 iOS 与 Web 的**中国神话天宫风 · 仙界星盘三合一肉鸽塔防游戏**（与原 `Chess-v1` 项目完全独立）。

- **在线试玩 (GitHub Pages CI/CD 自动部署)**：https://timclh.github.io/Tiangong-TD/
- **AI 视觉热替换槽位说明**：[`frontend/public/tiangong/README.md`](./frontend/public/tiangong/README.md)

## 核心玩法
1. **2.5D 天宫星盘（7×8 网格）**：顶部为九幽魔界裂隙，中部为天河弱水（减速带），底部为南天门凌霄宝殿。
2. **五大仙家棋子（1★ → 2★ → 3★ 法天象地）**：
   - **【兵】** 南天门天兵 → 金甲巨灵将 → **3★ 托塔李天王**（九宫震地减速）
   - **【車】** 雷部神车 → 九天应元雷尊 → **3★ 雷震子·风雷翼**（十字贯穿天雷）
   - **【馬】** 天河战骑 → 哮天战神 → **3★ 二郎显圣真君**（日字八方天眼暴击）
   - **【炮】** 兜率紫金炉 → 三昧真火炮 → **3★ 哪吒·火莲法相**（隔山打牛真火轰炸）
   - **【相】** 八卦仙阵 → 瑶池蟠桃阵 → **3★ 齐天大圣·法相**（仙阵攻速光环 + 定海神针横扫）
3. **15 波妖潮 + 5 大神话 Boss + 肉鸽三选一【天道法旨】**。
